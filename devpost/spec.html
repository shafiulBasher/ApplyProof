Technical spec · Build With AI: Basics

ApplyProof Approved

A local web app (Next.js) · browser storage · free Gemini Flash · plain-code checker

In plain language: ApplyProof runs on your laptop and opens in your browser. Your files and results live in the browser's own filing cabinet. A small helper on your laptop reads PDFs and holds the secret AI key. Gemini's only job is to list the guideline's requirements with quotes, and only the guideline's text is ever sent to it. Your own documents never leave your laptop. Plain code then verifies every quote and makes every pass/fail decision. A guideline is read once and remembered, so reruns are instant, free, and compare the same rules.

Run it & record it

  1. npm install
  2. Copy .env.example → .env.local, then add the free GEMINI_API_KEY and GEMINI_MODEL from AI Studio
  3. npm run samples, then npm run dev, then open http://localhost:3000
  4. Record: create the "Global Future Scholars Scholarship" application, upload the samples, run, see the CV Action Needed, replace it with the 2-page CV, rerun, and see What Changed → Passed

Where it could break

Free quota reached / Gemini down
A plain message, previous results unchanged, no paid fallback ever. The demo rerun doesn't need Gemini.
Wrong quote or bad JSON from the AI
The quote verifier turns that finding into Needs Verification. Bad JSON gets one retry, then a plain error with previous results kept.
Scanned PDF
The PRD error message, and the file stays listed for replacing. A scanned guideline keeps Run disabled.
Browser storage full
It names the item that wasn't saved, so nothing is lost silently.

Decisions & the open question

  • Yours: Gemini Flash free tier, swappable, stops gracefully when the quota ends · JS PDF reading, no OCR · local + video · synthetic docs · key server-side only · demo path first
  • Recommended & accepted: Next.js + TypeScript, Tailwind, quote verification in code
  • Your useful unknown: "Is a free model good enough?" It gets tested first with test-extraction: every expected requirement found and every quote verified. If not: tighten the prompt → another Flash variant → Groq via the adapter.
Changes made in review: the disclosure appears before the first upload and says accurately that only the guideline's text goes to Google · document types come from the filename (no AI) · the Outdated fingerprint uses content hashes + the page-by-page guideline text, so it catches a replaced file even with identical counts · cached requirements keep their page texts.
